# Glrk UI — Component Wrapper Reference

Glrk UI is a shadcn/ui + Base UI wrapper library for React + TypeScript + Tailwind v4.
Components ship as thin wrappers that reduce boilerplate while exposing full primitive access.

Install via shadcn CLI:
  npx shadcn@latest add @glrk-ui/<component-name>

Registry entry in components.json:
  { "registries": { "@glrk-ui": "https://ui.glrk.dev/registry/{name}.json" } }

## Type System

All selection components share a common type system from types/general.d.ts:

  type allowedPrimitiveT = string | number | boolean
  type itemT = { label: ReactNode; value: allowedPrimitiveT; className?: string; disabled?: boolean }
  type groupT = { group: string; items: itemT[]; className?: string }
  type itemsT = (allowedPrimitiveT | itemT | groupT | "---")[]

"---" is a visual separator. Primitives use the same value as label.

Menu-specific types (menuItemsT) extend itemsT with:
  - shortcut: string — keyboard shortcut display
  - variant: "destructive" — destructive item styling
  - submenu: string — creates nested submenu (label string, not ReactNode)
  - { group: string, items: [] } — groups items under a label

String conversion: Base UI controlled components use strings internally. Use `parseAllowedPrimitive(str)` from lib/utils to convert back to original type. Or keep state as string.

## Overlay Family — Dialog · AlertDialog · Sheet · Drawer

These four components share nearly identical structure. Dialog is documented fully; the others note only differences.

### Dialog — components/ui/dialog.tsx
Wrapper: DialogWrapper
Base: Base UI Dialog

Props:
  trigger?: ReactNode          — content for auto-wrapped trigger button
  triggerCls?: string          — CSS for trigger
  triggerProps?                — Omit<Dialog.Trigger.Props, 'children'|'className'>
                                 use render for custom element, handle for detached trigger
  title?: ReactNode
  description?: ReactNode      — set "" to hide
  children?: ReactNode         — renders between header and footer
  showCloseButton?: boolean    — default true
  contentCls?: string
  headerCls?: string
  titleCls?: string
  descriptionCls?: string
  cancel?: ReactNode           — cancel button text, "" to hide, default "Cancel"
  action?: ReactNode           — action button text, "" to hide
  loading?: boolean            — disables buttons, shows spinner, blocks close
  footerCls?: string
  actionCls?: string
  cancelCls?: string
  onAction?: () => void
  onCancel?: () => void
  // All Dialog.Root props forwarded: open, onOpenChange, handle, defaultOpen, etc.

Detached trigger: use Dialog.createHandle() from @base-ui/react/dialog, pass handle to triggerProps and wrapper.
Multiple triggers with payload: pass typed handle and payload to DialogTrigger.
Nested dialogs: render DialogWrapper inside children of another DialogWrapper.
Custom footer: set action="" cancel="", render DialogFooter/DialogClose inside children.

Also exports: DialogTrigger, DialogClose, DialogFooter (primitives)

---

### AlertDialog — components/ui/alert-dialog.tsx
Wrapper: AlertDialogWrapper

Same props as DialogWrapper EXCEPT:
  - Adds: media?: ReactNode — icon/image rendered above title in header
  - No showCloseButton prop (alert dialogs don't have X close)
  - Default title: "Are you absolutely sure?"
  - Default description: "This action cannot be undone..."
  - Default action: "Confirm"

Detached trigger: AlertDialog.createHandle() from @base-ui/react/alert-dialog

---

### Sheet — components/ui/sheet.tsx
Wrapper: SheetWrapper

Same props as DialogWrapper PLUS:
  - side?: 'top' | 'bottom' | 'right' | 'left'  — default "right"

Sheet uses Dialog.Root underneath — same handle/detached trigger pattern applies.
Also exports: SheetClose, SheetFooter

---

### Drawer — components/ui/drawer.tsx
Wrapper: DrawerWrapper

Same props as DialogWrapper EXCEPT:
  - No showCloseButton prop (Drawer has no X close button)

Additional Drawer-only props:
  - side?: 'bottom' | 'top' | 'left' | 'right'  — default "bottom"
  - swipeDirection — forwarded to Drawer.Root (match to side)
  - snapPoints?: number[]  — e.g. [0.4, 1] for snap heights
  - modal?: boolean  — default true; false = page stays interactive

Base: Base UI Drawer (not Dialog).
Also exports: DrawerClose, DrawerFooter

## Menu Family — Menu · Menubar · ContextMenu

All three use menuItemsT and share rendering logic. Plain, checkbox, and radio variants exist for each.

### Menu (Dropdown) — components/ui/menu-wrapper.tsx
Wrappers: MenuWrapper, MenuCheckboxWrapper, MenuRadioWrapper
Base: Base UI Menu

MenuWrapper props:
  trigger: ReactNode           — required
  triggerCls?: string
  triggerProps?                — Omit<MenuTrigger.Props, 'children'|'className'>
  items: menuItemsT            — see type below
  itemCls?: string
  groupCls?: string
  groupLabelCls?: string
  contentProps?                — forwarded to MenuContent
  onSelect?: (value: allowedPrimitiveT) => void
  // All Menu.Root props forwarded

menuItemsT item shapes:
  "Simple string"
  42 / true                    — primitives
  "---"                        — separator
  { label, value, shortcut?, variant?: "destructive", className? }
  { group: "Label", items: [...] }
  { submenu: "Label", items: [...] }  — nested submenu

MenuCheckboxWrapper additional props:
  items: menuInputItemsT
  checked?: allowedPrimitiveT[]
  onCheckedChange?: (value, checked) => void
  indicatorAt?: "left" | "right" | ""  — default "left"; "" hides indicator

MenuRadioWrapper additional props:
  items: menuInputItemsT
  value?: allowedPrimitiveT
  onValueChange?: (value) => void
  indicatorAt?: "left" | "right" | ""  — default "left"; "" hides indicator

---

### Menubar — components/ui/menubar-wrapper.tsx
Wrappers: MenubarWrapper, MenubarCheckboxWrapper, MenubarRadioWrapper
Base: Base UI Menubar

MenubarWrapper props:
  items: {
    key: string;
    trigger: ReactNode;
    items: menuItemsT;
    triggerCls?: string;
    itemCls?: string; groupCls?: string; groupLabelCls?: string;
    contentProps?;
    onSelect?: (value) => void;
  }[]
  triggerCls?: string           — global, merged with per-menu
  triggerProps?                 — global
  itemCls?: string              — global
  groupCls?: string             — global
  groupLabelCls?: string        — global
  contentProps?                 — global
  onSelect?: (value) => void    — global fallback
  // All Menubar.Root props forwarded

Per-menu props override global ones.

MenubarCheckboxWrapper: same items array shape (items: menuInputItemsT) + global checked, onCheckedChange, indicatorAt
MenubarRadioWrapper: same items array shape (items: menuInputItemsT) + global value, onValueChange, indicatorAt

### ContextMenu — components/ui/context-menu-wrapper.tsx
Wrappers: ContextWrapper, ContextCheckboxWrapper, ContextRadioWrapper
Base: Base UI Context Menu

Key difference from Menu: triggered by right-click on children (no trigger prop).
  children: ReactNode          — receives the right-click event (required)

ContextWrapper props (no trigger/triggerCls/triggerProps):
  children: ReactNode
  items: menuItemsT
  itemCls?: string
  groupCls?: string
  groupLabelCls?: string
  contentProps?
  onSelect?: (value) => void

ContextCheckboxWrapper: children + items (menuInputItemsT) + checked + onCheckedChange + indicatorAt
ContextRadioWrapper: children + items (menuInputItemsT) + value + onValueChange + indicatorAt

## Date Picker — components/ui/date-picker/

Install: npx shadcn@latest add @glrk-ui/date-picker
Base: @daypicker/react (DayPicker v9)

Exports: Calendar, CalendarDayButton, CalendarDropdown, DatePicker, DateTimePicker

### Calendar — components/ui/date-picker/calendar.tsx

Styled DayPicker wrapper. Accepts all DayPicker.Root props plus:
  buttonVariant?: 'default' | 'destructive' | 'outline' | 'secondary' | 'ghost' | 'link'
                              — nav button variant, default "ghost"

captionLayout defaults to "label"; pass "dropdown" for month/year dropdowns.
CalendarDropdown renders month/year selects using shadcn Select.
CalendarDayButton renders day cells using shadcn Button with range/selection data-attrs.

### DatePicker — components/ui/date-picker/date-picker.tsx
Wrapper: DatePicker

Calendar inside a Popover trigger. Supports single, multiple, and range selection.

type Selected = Date | Date[] | DateRange | undefined
  DateRange = { from?: Date; to?: Date }  (from @daypicker/react)

Props:
  mode?: 'single' | 'multiple' | 'range'  — default "single"
  selected?: Selected
  onSelect?: (...args: any[]) => void
  open?: boolean
  onOpenChange?: (open: boolean) => void
  placeholder?: string                     — default "Pick a date"
  dateFormat?: string                      — date-fns format string, default "dd/MM/yyyy"
  triggerProps?: Omit<Button.Props, 'children'>
  align?: 'start' | 'center' | 'end'      — popover alignment, default "start"
  // All Calendar (DayPicker) props forwarded except mode/selected/onSelect

Auto-close: single → closes on select; range → closes when both from + to are set; multiple → stays open.

Trigger display:
  single   → formatted date or placeholder
  multiple → "N dates selected" (or formatted if only 1)
  range    → "from - to" or just "from" if no end

### DateTimePicker — components/ui/date-picker/date-time-picker.tsx
Wrapper: DateTimePicker

Calendar + scrollable time slot list side-by-side inside a Popover. Single date+time only.

type MinuteStep = 1 | 5 | 10 | 15 | 20 | 30
type HourFormat = 12 | 24

Props:
  selected?: Date
  onSelect?: (date: Date | undefined) => void
  open?: boolean
  onOpenChange?: (open: boolean) => void
  placeholder?: string                     — default "Pick date & time"
  dateFormat?: string                      — date-fns format; default "dd/MM/yyyy HH:mm" (24h) or "dd/MM/yyyy hh:mm a" (12h)
  minuteStep?: MinuteStep                  — time slot interval, default 5
  hourFormat?: HourFormat                  — 12h/24h display, default 24
  triggerProps?: Omit<Button.Props, 'children'>
  align?: 'start' | 'center' | 'end'      — default "start"
  disablePast?: boolean                    — disables past dates + past times on today, default false
  minDate?: Date                           — disable dates before this
  maxDate?: Date                           — disable dates after this
  minTime?: Date                           — disable time slots before this time (applies on same day)
  // All Calendar (DayPicker) props forwarded except mode/selected/onSelect/disabled

Toolbar buttons: Now (selects current time snapped to minuteStep), Clear (clears selection), Done (closes popover).
When day changes, existing time is preserved but snapped forward to effectiveMinTime if on a restricted day.

## Form — components/ui/form.tsx

Wrapper: Form
Base: Base UI Form

Props:
  errors?: Record<string, string | string[]>    — server-side errors keyed by field name; propagated via context to Field.Root with matching name
  onFormSubmit?: (values: Record<string, unknown>, event) => void  — receives parsed form values; preventDefault called automatically
  validationMode?: 'onSubmit' | 'onBlur' | 'onChange'  — default "onSubmit"
  actionsRef?: RefObject<{ validate: (fieldName?: string) => void } | null>  — imperative validate()
  className?: string
  children?: ReactNode

Use with Field, FieldLabel, FieldNativeError from components/ui/field.tsx for native HTML validation.

Native validation pattern:
  <Form validationMode="onChange" onFormSubmit={handleSubmit}>
    <Field name="email" validate={(val) => !val ? "Required" : null}>
      <FieldLabel>Email</FieldLabel>
      <Input name="email" required />
      <FieldNativeError />
    </Field>
  </Form>

Server errors auto-clear when field values change.

## Toast — components/ui/toast.tsx
Wrapper: Toaster + useToast hook
Base: Base UI Toast

Setup: wrap app (or subtree) in <Toaster>. Call useToast() inside.

useToast() returns:
  toast.add(options) → string id
  toast.success(description, options?) → string id
  toast.error(description, options?) → string id
  toast.warning(description, options?) → string id
  toast.info(description, options?) → string id
  toast.promise(promise, { loading, success, error }, options?) → Promise
  toast.update(id, partialOptions)
  toast.close(id?, position?)  — omit id to close all

toast.add options:
  title?: ReactNode
  description?: ReactNode
  type?: "default"|"success"|"error"|"warning"|"info"|"loading"
  timeout?: number             — ms, 0 = persistent, default 5000
  priority?: 'low' | 'high'   — aria-live politeness
  position?: toastPositionT
  actionProps?: ButtonProps    — action button inside toast
  onClose?: () => void
  onRemove?: () => void
  icon?: ReactNode | null      — null suppresses icon

toastPositionT: "top-left"|"top-center"|"top-right"|"bottom-left"|"bottom-center"|"bottom-right"

Toaster props:
  position?: toastPositionT    — default "bottom-right"
  timeout?: number             — default 5000
  limit?: number               — max visible per position, default 3
  swipeDirection?: string[]    — default ['down','right']
  showClose?: boolean          — default true
  viewportCls / toastCls / contentCls / titleCls / descriptionCls / actionCls / closeCls

External manager (outside React): use createToastManager() + ToastProvider with toastManager prop.

## Common Patterns

### Controlled open state (all overlays)
  const [open, setOpen] = useState(false)
  <DialogWrapper open={open} onOpenChange={setOpen} ... />

### Async action with loading
  const [loading, setLoading] = useState(false)
  async function handle() {
    setLoading(true); await action(); setLoading(false); setOpen(false)
  }
  <DialogWrapper loading={loading} onAction={handle} ... />

### Custom trigger element
  triggerProps={{ render: <a href="#" />, nativeButton: false }}

### Render-prop trigger (Popover, Tooltip)
  triggerProps={{ render: (props, state) => <button {...props}>{state.open ? "Close" : "Open"}</button> }}

### Items with groups and separators
  items={[
    "Simple item",
    { label: "Custom", value: "val", className: "..." },
    "---",
    { group: "Group", items: ["A", "B"] },
  ]}

### Type-safe primitive conversion
  import { parseAllowedPrimitive } from "@/lib/utils"
  onValueChange={v => setState(parseAllowedPrimitive(v))}
